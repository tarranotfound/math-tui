# Example expressions

These examples can be used as manual checks once the evaluator is implemented.

| Expression | Expected result |
| --- | ---: |
| `2 + 3` | `5` |
| `8 - 3 * 2` | `2` |
| `(8 - 3) * 2` | `10` |
| `7 / 2` | `3.5` |
| `-4 + 6` | `2` |
| `1.25 + .75` | `2` |

Use these examples as behavioral expectations, not as evidence of implemented functionality.
