# Project overview

`math-tui` is a terminal calculator intended to be driven with both the keyboard and a cursor.

## Goals

- Keep the interface usable in a small terminal.
- Make common arithmetic quick to enter and revise.
- Keep input, evaluation, and presentation separate.
- Provide predictable keyboard navigation.

## Non-goals for the first iteration

- Symbolic algebra or computer algebra.
- A general-purpose programming language.
- Network access or account features.

This document describes intended behavior, not a claim that every feature is implemented.
