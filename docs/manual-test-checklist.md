# Manual test checklist

Use this checklist when validating the interactive terminal experience.

- [ ] Launch in a normal terminal window.
- [ ] Enter an expression using only the keyboard.
- [ ] Move the cursor and insert a character in the middle.
- [ ] Delete characters before and after the cursor.
- [ ] Evaluate a valid expression.
- [ ] Submit malformed input and inspect the error feedback.
- [ ] Navigate to an earlier history entry.
- [ ] Resize the terminal while an expression is present.
- [ ] Exit and confirm the terminal behaves normally afterward.

These checks complement automated parser and evaluator tests.
