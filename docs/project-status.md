# Project status

This repository currently contains project documentation and behavioral expectations for a terminal calculator.

## Documentation scope

The documents describe intended parser, evaluator, input, history, rendering, and testing behavior. They are design notes, not proof that those features are implemented.

## Next engineering milestones

1. Establish the executable project structure.
2. Implement and test the arithmetic core.
3. Connect the editor to the parser and evaluator.
4. Add terminal rendering and history navigation.
5. Validate behavior across terminal sizes and common keyboard input.

Update this page as implementation milestones are completed.
