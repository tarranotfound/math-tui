# Release checklist

Before tagging a release, verify the following:

- [ ] The project builds from a clean checkout.
- [ ] Parser and evaluator tests pass.
- [ ] Invalid input is handled without losing the current draft.
- [ ] Keyboard help matches the actual bindings.
- [ ] The application exits without leaving the terminal in a modified state.
- [ ] README instructions match the current implementation.
- [ ] Known limitations are documented.
