# Roadmap

A practical development sequence for the calculator.

1. Establish a minimal terminal application and clean exit behavior.
2. Define the expression syntax and evaluator behavior.
3. Add editable input and a visible cursor.
4. Add a scrollable calculation history.
5. Add keyboard navigation and help.
6. Add automated tests for parsing and arithmetic.
7. Polish terminal resizing and error recovery.

Keep each stage independently testable. Update this roadmap as implementation decisions change.
