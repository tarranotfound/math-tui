# Keyboard interaction

Proposed default bindings; adjust them to match the final terminal library and avoid conflicts.

| Key | Action |
| --- | --- |
| Enter | Evaluate the current expression |
| Backspace | Delete before the cursor |
| Delete | Delete at the cursor |
| Left / Right | Move the expression cursor |
| Home / End | Move to the start / end |
| Up / Down | Browse calculation history |
| Esc | Clear transient selection or close help |
| Ctrl+C | Exit cleanly |

Show the active bindings in an in-app help view.
